3DDSG DRONE NAVIGATION - COMMANDS
Run from the repo root in experiment_terminal.bat (cf-env active).
All options of a script: python scripts\<name>.py --help

FLY
  fly_route.py "from A to B"       Plan a route and fly it.
      --backend sim|crazyflie      Simulation (default) or the real drone.
      --rooms 2 2  --depth 2       Virtual rooms: widths and depth in m.
      --height 0.5                 Flight height above the floor in m.
      --velocity 0.2               Speed in m/s. Above 0.3 is untested.
      --margin 0.25                Distance kept from walls in m.
      --max-deviation 0.5          Land if this far from the plan in m.
      --yaw 0                      Real drone: nose direction in degrees from +x.
      --uri radio://0/80/2M        Radio address.
      --skip-dry-run               Real drone: skip the simulation check.
    The real drone flies only after a clean simulation run. Ctrl+C lands.

REAL-DRONE CHECKS (in this order)
  check_sensors.py                 Read the sensors without flying.
      --watch                      Live values until Ctrl+C.
      --shake                      15 s vibration test in your hand.
    Shows the Multi-ranger ranges when the deck is mounted.
  prop_test.py                     Spin the propellers without take-off.
  hover_test.py                    Take off, hover, fly forward, land.
      --live                       Print motors, height, position, battery.
      --distance 0                 Hover only.
      --height, --velocity, --hover-time, --min-battery

GRAPH
  ifc_pipeline.py model.ifc --storey 4F
                                   IFC storey to simulated flights in one step.
                                   Without --storey: list the storeys.
  ifc_to_graph.py model.ifc out --storey 4F
                                   Convert one IFC storey to a graph folder.
  graph_tools.py export-fake out   Write the generated test graph.
  graph_tools.py validate folder   Check a graph folder.
  graph_tools.py route folder "from A to B"
                                   Plan a route on a graph folder.
  check_routes.py                  Collision check and Open3D view of routes.

LIMITS
  Bright room, textured floor. Height 0.2 to 3.0 m.
  Battery 3.7 V or more at take-off.
  backends\crazyflie.py is not flight-tested yet.
  With a Multi-ranger deck, the drone lands if anything is closer than 0.2 m
  (checked at each waypoint).
